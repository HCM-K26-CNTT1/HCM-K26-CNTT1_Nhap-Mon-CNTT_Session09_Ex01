
# Giới thiệu dự án

## 1. Tên dự án
Quản lý thông tin sinh viên

## 2. Mục tiêu
Dự án nhằm hỗ trợ lưu trữ, quản lý và tìm kiếm thông tin sinh viên thuận tiện hơn.

## 3. Chức năng chính
- Thêm thông tin sinh viên.
- Chỉnh sửa thông tin sinh viên.
- Tìm kiếm thông tin sinh viên.

## 4. Công cụ sử dụng
- Microsoft Word: soạn thảo nội dung ban đầu.
- StackEdit: chỉnh sửa Markdown.
- Git và GitHub: quản lý và lưu trữ sản phẩm.
